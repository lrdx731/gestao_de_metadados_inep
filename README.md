Este repositório é referente à minha primeira pesquisa na universidade.
A pesquisa era sobre gestão de metadados, que são dados sobre dados, utilizando uma tabela disponível no site do INEP,
sobre o censo do ensino superior do ano de 2024. 
Foram utilizados no projeto: Plataforma openmetadata, conteinirização em docker, Postgresql e bibliotecas em python, como pandas e sqlalchemy.
